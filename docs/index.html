Abstract

A nonparametric mixture prior, scoped by n

From the MDPI manuscript. Scopes are split: 56-dataset geometry, 12-dataset kNN, 12-core flow matching. Captions here contain no TeX pointers.

Standard autoencoders for single-cell transcriptomics learn latent spaces whose cluster structure emerges only post hoc through K-means or community detection, leaving cluster count and boundary quality uncontrolled during training. Here we ask whether imposing an adaptive nonparametric prior can shift this balance. We equip a feedforward autoencoder with an online Dirichlet Process Mixture Model (DPMM) prior that refits cluster assignments throughout training and directly regularizes latent compactness and separation.

56-dataset geometry–concordance screen. Across 56 scRNA-seq datasets the DPMM prior produces a pronounced geometry–concordance trade-off: cluster compactness (ASW) improves by 127% and Davies–Bouldin overlap drops by 47%, while label-recovery metrics decline (NMI −17%, ARI −21%).

12-dataset kNN probe. On a separate 12-dataset kNN probe, downstream accuracy falls from 0.784 to 0.725.

12-core matched pairs and DPMM-FM. Wilcoxon signed-rank tests on the 12-core matched pairs confirm that the geometry gains are significant with large Cliff’s δ effects while concordance losses remain bounded and non-significant. A second-stage conditional-flow refinement (DPMM-FM), evaluated on that same 12-core ablation, further improves projection fidelity (DRE 0.751, LSE 0.695, DREX 0.873) at additional concordance cost, revealing a three-tier operating regime: prior-free for label recovery, DPMM for manifold geometry, and DPMM-FM for visualization fidelity.

11 named externals. Against 11 named external methods (N_pairs = 12; 407 = 11 × 37 metric rows) DPMM-Base wins 70.5% of core-metric comparisons (p < 0.05; 31/44).

Dentate GO (F06). Gene Ontology enrichment on saved dentate components confirms that geometry-improved latent partitions recover coherent biological programs with complete GO identifiers. Rather than claiming universal superiority, this study characterizes the operating envelope of nonparametric mixture priors and identifies the task contexts — trajectory analysis, manifold visualization, and program-level annotation — where adaptive geometric structure outweighs label-counting accuracy.

Install

Core Python workflow:

pip install -e ".[dev]"

Single-cell extras:

pip install -e ".[dev,bio]"

Optional graph encoder support:

pip install -e ".[dev,graph]"

Families in this repo

Pure-AE, DPMM-Base, DPMM-Transformer, DPMM-Contrastive, and DPMM-FM. Benchmarks and figure tooling live under benchmarks/, eval_lib/, and refined_figures/.
