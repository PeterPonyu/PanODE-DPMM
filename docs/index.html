Public Python package

PanODE-DPMM

Research code for Dirichlet-process-mixture regularised autoencoders, ablation variants, and local evaluation utilities.

What this page is

A companion for the public GitHub tree. It lists install commands and module paths. It does not host manuscript figures, result tables, or an article DOI.

Package map

models/
DPMM-regularised autoencoder variants and shared layers
eval_lib/
Portable evaluation helpers used by local runners
benchmarks/
Smoke and series runners for a caller-supplied .h5ad path
experiments/
Orchestration entry points for optional local jobs
refined_figures/
Scripts that emit figures on the machine that has the data
model-arch-viewer/
Optional local Next.js preview; not this public page
tests/
Automated checks run by pytest and CI

Install

pip install -e ".[dev]"

Optional extras: dev,bio and dev,graph. Point runners at a local .h5ad with --data-path or PANODE_DATASETS_ROOT.
