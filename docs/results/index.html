Package

The public repository is a Python package plus local runners. Figure scripts stay in the tree so a clone can render locally; this site does not publish those outputs.

models/
DPMM-regularised autoencoder variants and shared layers
eval_lib/
Portable evaluation helpers used by local runners
benchmarks/
Smoke and series runners for a caller-supplied .h5ad path
experiments/
Orchestration entry points for optional local jobs
refined_figures/
Scripts that emit figures on the machine that has the data
model-arch-viewer/
Optional local Next.js preview; not this public page
tests/
Automated checks run by pytest and CI
